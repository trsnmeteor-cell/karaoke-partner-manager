    設定・共有

    複数端末で共有する（クラウド同期）

    PC・iPhone・Androidのどれでも、同じ「ウェブアプリURL」を開けば同じデータが見られます。準備は下の「共有の準備（GAS）」で行い、発行されたURLをここに貼り付けてください。

    GitHubの非公開リポジトリにデータファイルを置いて共有します。Google側の準備は不要です。リポジトリとトークンの作り方は下の「共有の準備（GitHub）」を見てください。

    トークンはこの端末のブラウザにのみ保存されます。データ用リポジトリだけを操作できる「Fine-grained」トークン（Contents: Read and write）を使ってください（トークン作成ページを開く）。

    —

    同期エラー後や、別端末で作ったデータが消えてしまった場合の復旧に使います。

    ファイルで共有・バックアップ

    クラウド同期を使わない場合や、データのバックアップに。書き出したJSONファイルを別の端末で読み込めます。

    共有の準備（GitHub・Google不要）
    1. github.com でデータ用の非公開リポジトリを作ります：「New repository」→ 名前例 karaoke-partner-data → Private を選んで作成。店舗名や写真が入るため必ず非公開にします（アプリ本体のGitHub Pages用リポジトリとは別にします）。
    2. Fine-grained personal access tokens の作成ページでトークンを作成：名前と有効期限を設定 →「Repository access」は「Only select repositories」で上のリポジトリだけを選択 →「Permissions」の Contents を Read and write に → 生成されたトークン（github_pat_…）をコピー（一度しか表示されません）。
    3. 上で「GitHub」タブを選び、リポジトリ／ブランチ（main）／ファイル名（既定）／トークンを入力 →「保存して接続」。データファイルは自動で作成されます。
    4. 他の端末では、同じアプリURLを開き、同じリポジトリと端末ごとに発行したトークンを入力すれば共有完了です。

    トークンを持つ人はデータを読み書きできます。人に渡さず、不要になったら GitHub のトークン一覧から失効させてください。

    共有の準備（GAS・Googleドライブを使う場合）
    1. このアプリのHTMLファイルをPCに保存します（配信された karaoke-partner-manager.html）。
    2. drive.google.com を開き、「新規 → ファイルアップロード」でそのHTMLをアップロードします（ファイル名は karaoke-partner-manager.html のまま）。
    3. script.google.com を開き「新しいプロジェクト」を作成 → エディタの既存コードをすべて消して、下のコードを貼り付けます。
    4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選択。
      「次のユーザーとして実行：自分」「アクセスできるユーザー：全員」にして「デプロイ」。
    5. 初回のみ承認を求められるので「アクセスを承認」→ 自分のアカウント → 「詳細」→「安全でないページに移動」→「許可」。
    6. 表示されたウェブアプリのURL（末尾が /exec）をコピー。各端末のブラウザでそのURLを開けばアプリが起動し、自動で同期がONになります。

    このURLを知っている人はデータを読み書きできます。関係者以外にはURLを共有しないでください。

    データの保存先はあなたのGoogleドライブ内の「karaoke_partner_db.json」です。アプリを更新したときは、ドライブ上のHTMLファイルを新しいものに上書きします。
    ※最初の同期は、データが入っている端末を先に接続して完了させてから、他の端末を接続してください。
